# 🎮 My Little Life

A cute 2D life simulation game built with HTML, CSS, and JavaScript. Create your character, explore different locations, earn virtual money, build relationships, and customize your space!

## ✨ Features

- 🎨 Character customization
- 🏡 Explore different locations
- 💰 Earn virtual money and manage daily needs
- 💕 Interact with other characters
- 🛋️ Shop for items and arrange furniture
- 💾 Save game progress in your browser

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Keep `index.html`, `styles.css`, and `game.js` in the same folder.
3. Open `index.html` in your browser.

## 🎯 About This Project

I built My Little Life as a personal learning project to practise front-end development and create an interactive browser game. This project helps me develop my programming skills and learn how HTML, CSS, and JavaScript work together.
